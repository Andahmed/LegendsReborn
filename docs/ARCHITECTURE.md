# Architecture / File Map

Dependency rule: `Combat` (engine-free) <- `Meta` (engine-free) <- `Services` / `Core` (Unity) <- `Bootstrap`, `Presentation`, `UI`.

Server (`Server/`) can re-run `Combat` + `Meta` logic for authority/anti-cheat.

| File | Owner role | Responsibility | Work on | Status |
|---|---|---|---|---|
| `Assets/Scripts/Combat/Types.cs` | Client Programmer - Combat | Combat data types: Faction/Role/Rarity enums, FactionChart (+25% advantage), SkillSpec, UnitSpec, BattleEvent, SeededRng. | Add new enums/fields only with a GDD change. Tune FactionChart.AdvantageBonus. Keep this file free of UnityEngine. | Implemented |
| `Assets/Scripts/Combat/BattleSim.cs` | Client Programmer - Combat | Deterministic fixed-step auto-battle (2 front + 3 back, timed skills, energy ultimates, crit, 120s timeout). | Add buffs/debuffs/shields/DoT, team synergy (3+2 factions = +15% HP, mono-faction = +25% ATK), balance the damage formula, per-skill targeting rules. Must stay deterministic and engine-free. | Implemented (placeholder balance) |
| `Assets/Scripts/Core/HeroDefinition.cs` | Systems Designer | ScriptableObjects HeroDefinition/SkillDefinition: designer-editable hero and skill data converted to UnitSpec/SkillSpec. | Fill 20 hero cards for MVP (stats, skills, faction, role, rarity). Add lore/portrait/prefab references when art arrives. | Implemented |
| `Assets/Tests/EditMode/BattleSimTests.cs` | QA Engineer | EditMode tests for combat: faction cycle, determinism, front-row targeting, timeout, ultimate/heal. | Add a test for every combat rule added to BattleSim. | Implemented |
