# Style Guide

Direction (from the plan): stylized 3D, warm colors inspired by sand/gold/turquoise, simplified Arabic geometric ornament (arches, mashrabiya, arabesque) that is easy to reproduce.
Characters are readable from far away: strong silhouette, one dominant color, distinctive motion. UI is less crowded than the genre norm; features unlock gradually.
