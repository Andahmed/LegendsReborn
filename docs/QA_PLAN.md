# QA Plan

## Device matrix
12 Android (low/mid/high, screens and aspect ratios) + 4 iPhone. Test on weak networks and real store purchases at soft launch.

## Daily smoke test (every build)
Open -> battle -> save -> quit -> reopen (save intact) -> summon -> idle claim.

## Rules
- Bug tracker with severity; critical bugs block the next sprint's new features.
- Definition of Done includes QA sign-off.
- Crash-free sessions target >= 99.5%.
