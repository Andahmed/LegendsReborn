# Economy

| Resource | Used for | Sources |
|---|---|---|
| Gems (premium) | summons, extra energy, slots | quests, events, drops, ads, IAP |
| Gold | hero/gear upgrades | campaign, idle, selling |
| Exp | hero levels up to the ceiling | campaign, exp farms, quests |
| Hero shards | stars and star upgrades | duplicates, weekly shop, events |
| Gear materials | gear upgrades | custom farming stages, weekly boss |

## Rules
- Free path must reach endgame; spenders accelerate (no power that cannot be earned).
- Publish official pull rates and pity in the Summon screen.
- Do not change prices/rates without an A/B test and soft-launch data.
