# Scenes

Run **Sands > Setup Prototype** in the Unity Editor to create any missing scenes and register them in Build Settings:

1. `Boot` - contains `GameBootstrap` and routes to Home.
2. `Home` - minimal prototype home screen with an Enter Battle button.
3. `Battle` - 4v4 cube battle with HP bars and x1/x2/x4 speed buttons.

The setup command preserves existing scene files. Replace the prototype visuals and navigation with approved production content before release.
