# Data

- `Heroes/` - generated `HeroDefinition` assets (one prototype hero per core faction).
- `Skills/` - generated `SkillDefinition` active/ultimate assets.
- `Stages/` - stage data (enemy teams, rewards).
- `Economy/` - curves/tables from the economy ledger.

Run **Sands > Setup Prototype** in the Unity Editor to create any missing prototype hero and skill assets. Existing assets are preserved.
