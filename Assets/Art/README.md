# Art
- `Characters/` - hero models, textures, animations (idle/run/attack/skill/ultimate/hit/death). One folder per hero id.
- `Environments/` - 5 biomes (forest, desert, mountain, sea, ... per GDD), battle backdrops.
- `UI/` - icons, frames, Arabic geometric patterns, fonts (Arabic + Latin).
- `VFX/` - particles/shaders per faction; keep battles readable.
- `Audio/` - music, SFX, hero voice lines (6-8 voices for key heroes).

Budgets: mobile-friendly (low-end Android). Compress textures; atlas UI sprites. Do NOT place unused packs under `Resources/` (APK size).
